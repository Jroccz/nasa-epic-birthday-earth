# nasa-epic-birthday-earth
#How it works
retrieve_epic_photos: Gets photo information from NASA using the API key and date.
main: Asks the user for their birthday.
Photo URL: Creates a link to the NASA photo.
#How to run
Install requests: pip install requests
Run: python <your_file_name>.py
Enter a birthday in YYYY-MM-DD format.
Open the generated link to see the photo.
#Built with
Python, requests, and the NASA EPIC API.
